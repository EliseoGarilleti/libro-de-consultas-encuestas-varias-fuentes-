# Libro de Consultas - Tendencias Electorales

> Análisis longitudinal de intención de voto a partir de múltiples encuestas electorales

## 📊 Descripción

Este proyecto genera un **libro interactivo HTML** que consolida y analiza datos de múltiples encuestadoras (CIS, 40db, Sigma Dos, Sociométrica, Opina360, etc.) para ofrecer una visión comprehensiva de las tendencias electorales en España desde septiembre de 2023.

## 🎯 ¿Qué produce este proyecto?

El código genera un **sitio web estático** con visualizaciones interactivas que incluye:

### 1. Intención de Voto (IDV)
- **IDV General**: Evolución temporal de intención de voto para PSOE, PP, Vox, Sumar y Podemos
- **IDV por Género**: Tendencias segmentadas por hombres y mujeres
- **IDV por Edad**: Análisis por grupos etarios
- **IDV por CCAA**: Desglose por Comunidades Autónomas

### 2. Análisis de Transferencias de Voto
Para cada partido político (PSOE, PP, Vox, Sumar):
- Porcentaje de votantes fieles (retención)
- Fugas hacia otros partidos
- Movimientos hacia abstención/voto nulo
- Proporción de indecisos

### 3. Variación en Intención de Voto
- Cambios en puntos porcentuales respecto a septiembre 2023
- Tendencias al alza o a la baja por partido
- Desagregación por género y edad

### 4. Anexos
- **Tabla de IDV**: Datos numéricos completos con filtros y ordenación
- **Matriz de transferencias**: Cruce de recuerdo de voto vs. intención actual
